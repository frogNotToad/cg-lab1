# Лабораторная работа №1: Основы 3D-графики

**Вариант 5 — сфера (~100 вершин)**.

## Условие

Построить сферу (~100 вершин), спроецировать её на экран с помощью матриц проекции и
аффинных преобразований. Программа работает в реальном времени, проекцию и преобразования
можно менять динамически.

Дополнительные задания:

1. Переключение проекции (ортографическая / перспективная) в интерфейсе.
2. Элементы интерфейса для изменения позиции, поворота и растяжения фигуры.
3. Движение и вращение фигуры по сложной траектории (спираль на торе),
   пауза/воспроизведение, скорость, радиус, амплитуда, число витков.
4. Изменение цвета фигуры через `ImGui::ColorEdit3`.
5. Процедурные цвета вершин по их позиции в локальной системе координат;
   выбранный цвет умножается на цвет вершин.
6. Три объекта на сцене: у каждого объекта свой uniform-буфер и свой `VkDescriptorSet`.

## Сборка
```bash
cmake --preset msvc2026-debug # или
cmake --preset msvc-debug
```

```bash
cmake --build build-debug --parallel
```

## Запуск
```bash
./build-debug/Debug/vulkan-starter-app.exe
```
## Управление

Всё управление — в окне «Управление»:

- «Камера»: проекция, угол обзора, азимут, возвышение и расстояние камеры;
- «Объект»: выбор сферы, позиция, поворот (углы Эйлера), масштаб по осям, цвет;
- «Анимация»: воспроизведение/пауза, скорость, радиус, амплитуда и число витков траектории.
- **Ctrl + клик** по ползунку — ввод точного значения с клавиатуры.

## Структура

| Файл | Содержимое |
| --- | --- |
| `source/math.hpp` | векторы, матрицы 4×4, аффинные преобразования, `lookAt`, перспективная и ортографическая проекции |
| `source/application.cpp` | генерация сферы, буферы, дескрипторы, конвейер, анимация, интерфейс, запись команд |
| `shaders/sphere.vert/.frag` | вершинный и фрагментный шейдеры |
